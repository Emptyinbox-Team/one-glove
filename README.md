# One Glove

A missing-persons bureau for gloves. Post a lost glove or a found glove, get matched with its other half nearby, share the reunion. iOS (SwiftUI) + Supabase. Worldwide launch, Whistler as the first proving town.

## Start here
- **Product brief** — `docs/brief.md`
- **Walkthrough deck** — open `docs/walkthrough.html` in a browser (arrow keys to advance)
- **Brand vote (public site)** — https://emptyinbox-team.github.io/one-glove/ (source: `docs/index.html`, votes stored in Supabase `one_glove_brand_votes`)
- **Backend** — `supabase/` schema + 20-case demo seed (`supabase/README.md`)
